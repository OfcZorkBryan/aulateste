## O que existe

O arquivo [meu_app/app.py](meu_app/app.py) imprime mensagens simples para confirmar que o primeiro aplicativo está funcionando. Este repositório representa um exercício inicial, ainda em desenvolvimento.

## Executar

Com Python instalado, abra o terminal na pasta do projeto e rode:

```bash
python meu_app/app.py
```
